中文
----
本项目将官方字体子集化为 ZCOOLKuaiLe-Subset.woff2，仅用于手账风格的标题。
字符集为 GB2312 一级汉字、src/lib/i18n/zh.ts 全部字符、ASCII 可见字符与常用中文标点的并集。
原许可未声明保留字体名称，子集沿用原名，继续按 SIL OFL 1.1 分发。
生成脚本为 scripts/fonts/subset-title-font.py，生成元数据位于 src/app/fonts/ZCOOLKuaiLe-Subset.json。
Next.js 将字体输出至 .next/static/media，许可和本说明随 public/third-party-licenses/zcool-kuaile/
进入 Docker、npm、Electron、飞牛及安卓单机版的 server.zip。
安卓单机版和客户端版还在 APK 的 assets/licenses/zcool-kuaile/ 内附带本说明与许可。
客户端版从所连接的服务端加载字体。

English
-------
This project subsets the official font as ZCOOLKuaiLe-Subset.woff2 for Notebook-style headings.
The character set combines GB2312 level-one Han characters, every character in src/lib/i18n/zh.ts,
visible ASCII and common Chinese punctuation. The original license declares no Reserved Font Name.
The subset retains the original name and is distributed under SIL OFL 1.1.
The generator is scripts/fonts/subset-title-font.py. Metadata is in src/app/fonts/ZCOOLKuaiLe-Subset.json.
Next.js emits the font into .next/static/media. This notice and OFL.txt ship in
public/third-party-licenses/zcool-kuaile/ with Docker, npm, Electron, FnOS and the standalone Android server.zip.
Both Android modes also include these files in APK assets/licenses/zcool-kuaile/.
The Android client loads the font from its connected server.
