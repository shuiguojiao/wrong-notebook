# 练习与组卷

## 举一反三

从错题详情点击「再来一道类似的」进入举一反三，选择难度，由 AI 生成考查相同知识点的变式题。生成题型限定为填空题或解答题，题目内容不应携带题号、分值或选择题选项。

直接打开 `/practice` 而未提供题目参数时，页面会提示从一道题的详情页点「再来一道类似的」进入，并提供「去错题本」（`/notebooks`）与「回今天」（`/`）按钮。发生错误时也可通过页面内出口离开。

先独立作答，再查看答案与解析，并记录做对或做错。记录会关联原题，用于回看练习历史和评估掌握情况。

提交答案后自动判题：纯文字作答与标准答案写法一致（忽略空格、公式符号和"答案是"等前缀，选择题只比较选项字母）时直接判对；否则由 AI 对照标准答案和解析判定，并给出一句判定依据。等价写法（如 `1/2` 与 `0.5`）算对，多个答案只答出一部分算错。AI 判定失败时由用户自己选择结果。判定只是建议，保存前可以修改。

每道错题会暂存最近一次生成的变式题与解答。再次进入举一反三时直接显示这道题和生成时间，不再重新调用 AI；需要新题时点「重新生成」，新题会替换暂存内容。

保存练习结果时，自己的答案、解题思路及自动判题依据一并保存，可在原题的作答历史中展开查看。修改建议结果不会覆盖原始判题依据。判题会核对页面题目版本；若其他标签页已重新生成题目，当前页面停止自动判题并保留作答，可对照当前页面答案手动确认或重新加载新题。

### 拍照作答

原题复习和举一反三支持「键盘 / 手写 / 拍照」，无触摸的桌面浏览器显示「上传照片」。点「拍一张」调起系统后置相机，或「从相册选」，在裁剪弹窗中可向右旋转，只留下自己的解答部分。照片在本机处理 HEIC 和方向，裁剪后压到最长边 2000px、JPEG 从 0.85 逐级降质且每张不超过 1.5MB。打不开的照片会提示换一张。

最多保留 3 张照片，可逐张重拍、向右旋转 90°、删除或继续添加。任意文字、笔迹或照片即可提交，页签圆点标出已有内容。判题按手写图在前、照片在后的顺序发送，合计最多 4 张。照片仅留在当前作答内存中，提交和「撤回，继续写」后保留，换题清空。AI 看不清时可点「看不清，重拍一张」回到拍照页签，保留全部作答，不受 3 秒撤回窗口限制，也不产生作答记录。自评确认后保存的展示图由多图竖向拼接，对照与详情练习记录均可点击放大。

## iPad 与 Apple Pencil 手写作答

宽屏作答栏与题目栏按 3:2 分配，长题目可独立滚动；工具栏紧凑排列，画布按剩余视口高度展开。逻辑宽度固定 1000，高度按容器比例连续计算（无硬上限以避免极端比例下的死区），背景铺满，缩放不改写原始坐标。变矮后超出视区的笔迹仍保留，导出包含全部笔迹。

原题复习和举一反三的作答区都有「键盘 / 手写 / 拍照」。文字可选，有文字、笔迹或照片之一即可提交；切换保留内容，并一起判题。移动端题目在上、画布在下，宽屏（1024px 起）左题右答。画布以向量点保存当前页面内的草稿，旋转屏幕或调整窗口不会丢笔迹；刷新、离开题目或成功重新生成题目会清空未保存的草稿。

- 笔支持黑/蓝/红与三种粗细，Pencil 使用实际压感；鼠标和手指使用模拟压感。
- 橡皮按整笔擦除；撤销/重做支持最近 50 次操作，清空也可撤销。背景可选空白、方格、横线。
- 首次检测到笔输入后默认开启「仅限 Pencil」，浏览器记住是否检测过笔。开启时手指可滚动页面；关闭后手指可在画布书写。笔落下会接管未完成的触控笔画，屏蔽手掌触控。工具栏及画布外仍可滚动页面。
- 提交时裁剪笔迹并加边距、铺白底，比较 PNG/JPEG 后选较小的图片；长边不超过 1600px，图片不超过 1.5MB，必要时降低尺寸和质量。纸张辅助线不发送给 AI。导出失败保留草稿并提示重试；提交后只读。

含手写图片的答案始终由 AI 判题，要求识别答案、检查步骤并指出具体错误；不会仅因键盘答案匹配而直接判对。所配置的模型需支持图片输入，OpenAI/Azure、Gemini、Anthropic 均复用现有多模态传输。识别结果单独显示，不覆盖键盘答案；字迹无法辨认时 AI 应说明而非猜测，最终仍由你确认做对/做错。AI 请求失败时保留答案，可自行确认结果。

确认结果后，记录保存作答展示图片（`answerImageUrl`）、识别文字（`recognizedAnswer`）、键盘文字及判题依据，可在原题作答历史中展开查看。图片使用本地受鉴权存储，完整备份携带图片内容；旧备份缺少字段时恢复为 null。`POST /api/practice/grade` 接受可选的 `answerImages` data URL 数组（1–4 张）及兼容字段 `answerImage`，判题必须提供文字或图片。`POST /api/practice/record` 继续接受可选的单张 `answerImage` 与 `recognizedAnswer`。

判题接口支持按顺序提交最多 4 张答案图片，旧 `answerImage` 与新 `answerImages` 合并去重且旧图在前，每张仅限 PNG/JPEG/WebP、1.5MB。图片看不清时返回 `correct: null`、`unreadable: true`，保留原因并由用户自评。判题使用分开的原图，对照与确认保存使用本地竖向拼接的单张展示图（初始宽 1000px、白底、24px 浅灰分隔，JPEG 逐级压缩，必要时整体缩小到 1.5MB 以内）。当前界面仍由手写导出一张图。

手写图片在提交判题时发送给配置的 AI 提供商，遵循现有 AI 数据授权，见[隐私说明](../PRIVACY.md)。

iPad（≥768px）的提交按钮位于作答栏顶部，与打字/手写/拍照切换同行靠右，高度至少 44px。手机保留底部提交栏，手写工具移到纸张上方，内容与提交栏预留 48px 间隔。Pencil 落笔中及抬笔后 800ms 内忽略触摸提交，笔和键盘仍可提交。提交后立即进入对照，3 秒内可点「撤回，继续写」保留文字、笔迹和照片、中止判题并丢弃迟到结果；原题复习从暂停处继续计时。只有自评确认才保存作答记录，自评保存后的撤销提示仍独立使用。Pencil 触摸采用原生非被动监听防止误滚动，手指滚动设置保留；丢失抬笔、新笔接续或切入后台时保存已有笔画。新采集的笔压力映射到 0.35–1，笔的 thinning 为 0.45，非笔压感模拟保持原行为，旧点数据无需迁移。

## 掌握情况

掌握概率依据原题关联的实际作答历史评估，来源包括举一反三、试卷作答和重复导入。

- 优先使用 AI 评估；AI 调用失败时使用规则估算，并记录评估来源。
- 错题的状态由作答记录和掌握概率自动决定，不再手动标记：
  - **还没掌握**：包含内部 `new`（没有有效作答记录）与 `reviewing`（有记录但概率低于阈值或尚未评估）。
  - **已掌握**：有有效作答记录，掌握概率达到已掌握阈值，内部状态仍为 `mastered`。
- 已掌握阈值默认 50%，每个用户可在“设置 → 通用”中单独调整（1%～100% 的整数）；修改后状态筛选、统计和随机试卷的掌握范围立即按新阈值计算。
- 错题本与随机试卷使用「还没掌握 / 已掌握」范围；列表新增 `mastery=unmastered`，旧 `new`、`reviewing` 参数仍可分别精确筛选，打印沿用列表筛选。
- 没有可用作答记录时，掌握概率为空。
- 评估在后台执行，回填结果后可能需要稍等或刷新才能看到更新。

掌握概率用于辅助安排复习。它不保证学生已经理解题目，也不等同于考试得分。

## 今日复习

今天页与保留的 `/review` 路由共用今天复习区域，展示每日额度内的到期题。

今日题目列表与复习小结的题干预览均支持公式排版，行间公式在摘要中按行内公式显示。超长摘要保留完整公式或在公式前省略，不拆开公式定界符、命令或括号；超宽公式可横向查看。

- 英语和语文填空采用记忆类安排，其余学科与题型采用方法类安排；语文题型不能精确区分所有默写、背诵题，当前仅将填空类归为记忆类。
- 做对且有把握前进两轮，不太确定前进一轮；做错退两轮，连续两次做错回到第一轮。下次日期在合理窗口内选择已排估计用时最少的一天，并列用题目哈希分散。
- 做对但提前作答时，新间隔从原定到期日算起；其余间隔从最近一次作答的日期算起，作答记录来自原题复习、举一反三、手动录入、试卷和重复导入；“没做”的记录不影响计划。
- 完成全部复习轮次后不再安排日常复习；完成后又做错会从最后一轮继续调整。日期按应用时区计算，优先较早的复习轮次、逾期比例、到期日和题目 ID，再按科目轮流出题。
- 今天页（`/`）先展示应用时区日期、问候与预计分钟，再按科目列出今日复习题数和用时。科目前的方框为只读进度，有当日复习记录且该科在今日额度队列中无剩余题时自动打勾；点击待复习科目整行进入单科复习。首页与 `/review` 共用概览数据源。≥1024px 左任务右清单、状态与录入；768–1023px 单栏按任务、状态、清单、录入排序。平板默认展开前 6 题，手机默认折叠，可查看全部并渲染公式。识别与核对提示共用一张白纸卡，无内容时隐藏。加载用骨架，失败可重试，不显示假零。录入放在最后的「又错了新题？」中，点「拍照 / 相册」展开图片上传，「更多」提供文字、文件和 AI Agent。展开后切换入口保留上传队列、草稿恢复、确认流程与 `?notebook=` 目标。文字入口提示「把题目贴过来」，格式帮助默认折叠。贴纸奖励与连续复习天数来自只读进度服务。

点击开始或直接访问 `/review/session` 都会按剩余额度开始会话，不再按固定题量截断。开始时固定题目顺序，不预取下一题或生成变式；`autostart` 标记仍会移除，但刷新会按当前到期列表重新开始。已保存记录保留，页面草稿不跨刷新保存。

- **专注作答**：复习会话从加载起默认隐藏全局导航，空队列或无可作答内容的错误恢复外壳；已有卡片的保存错误及自带返回出口的收工小结保持专注，顶栏显示关闭、科目、第 n 题 / 共 m 题、队列剩余估时、跳过和细进度条。≥1024px 作答时按 55% / 45% 左题右答，题目纸卡展示材料和题目全文、长题在左栏滚动；右侧便签面板显示「我的答案」、打字 / 手写分段切换、可选思路和顶部「交卷，看看对不对」，作答区填满剩余高度。768–1023px 题目在上、作答在下，提交位于作答栏顶部。手机长题超过约六行默认摘要，可「展开全文」；作答使用底部非模态抽屉，可上下拖动、点击把手或按上下方向键展开与收起，收起或展开题目均保留文字和笔迹。软键盘弹出时抽屉随可视视口调整，仍可滚动看题及操作提交。作答阶段不挂载原图或出处入口，提交后显示「试卷原图」照片卡，点击进入整页出处查看器。复习手写默认横线纸，工具位于画布上方并预留掌侧空间，其他场景默认空白纸；旋转屏幕保留逻辑坐标，导出只包含笔迹。分段控件以圆点标记已有内容，「写下思路（可以不写）」可展开文本框。空提交提示先填写答案，继续支持 ⌘/Ctrl+Enter、重复提交保护、草稿和关闭确认。旧快照缺少估时数据时只显示题号进度。
- **一步确认**：提交后在同一张卡片内切换为对照并隐藏跳过，材料默认显示三行摘要、可展开全文。横屏沿用 55% / 45% 左题右结果，左栏材料下方显示带胶带的「试卷原图」照片卡，手机上下排列。≥1024px 时，作答与对照卡片占用进度条下方的剩余视口高度并预留底部安全区，左右栏内容分别滚动，提交位于作答栏顶部，自评按钮位于右栏底部。原图卡提交后才挂载，可打开整页出处与多区域框选。纯文字作答与标准答案一致（需要论证的题除外）时本地判对，不调用 AI。其他情况在后台判题。标题分别显示「做对了」「差一点」「正在看你的答案…」或「请自己对一对答案」。整题按「你写的 / 上次错答 / 参考答案」对照，判对用绿色圆章、判错用橙色方章。AI 提示用黄色便签展示一句摘要，详情可展开。手写识别、详细解析和类似题入口仍默认折叠。自评上方显示「这道题你现在觉得？」。判对时「还不太熟」保存 correct + unsure，主按钮「会了，下一题」保存 correct + sure。判错时「明天再见」保存 wrong，「我觉得我是对的」仅切换到两个判对自评按钮，继续选择后才保存。判题中或失败时由用户选择「没做对 / 还不太熟 / 会了」，分别保存 wrong / correct + unsure / correct + sure。数字快捷键 1 / 2 / 3 按当前保存按钮顺序映射，输入框聚焦时忽略。保存失败保留答案并可重试。
- 有未处理的用户可见核对问题时，提交后的「试卷原图」卡保留黄色圆点提示并显示「这道题可能与原图不一致 · 看原图」，展开后可点「看一眼」进入 `/checks?id=题目ID` 并优先查看该题，作答时隐藏提示，题目照常参与复习。
- **撤销**：保存后约 5 秒展示「已记录为… / 撤销」，最后一题的小结上也可撤销。成功后删除刚写入记录、按当前负载重算复习安排，并回到上一题的判题界面，保留文字、笔迹与判题依据；请求失败不改变当前进度。若下一题已有草稿，撤销前先确认放弃。
- **再来一道类似的**：仅在判题后的「再来一道类似的」折叠行中提供次要链接，在新标签页打开既有举一反三流程，保留当前复习界面；不提前生成题目，也不改变独立举一反三的保存方式。
- **跳过与关闭**：跳过不写记录、不改计划；有草稿时跳过或关闭需确认放弃。关闭后返回复习首页并提示已完成题数；当前会话不跨页面恢复。小结显示「这次做对 / 明天再见 / 彻底掌握」三格已保存结果；跳过单列「跳过 n 题，仍需复习」，不计作完成。掌握数只认本次前后状态由未掌握变为已掌握；会话开始与收工时读取同组题目的进度快照；取数失败或异步评估未完成时显示「– · 待确认」。白纸卡「今天的进步」按做对和「明天再见」分组列出可点击的公式题干预览，不生成上次错因。副标题显示已保存题数与本次前台作答分钟数（向上取整）。整组无跳过且全科今日队列重新核对为空时显示日期「搞定」章与「今天的错题清空啦」；未清空、核对失败或加练显示「这一组做完啦」，不盖当天完成章。主按钮「收工」回今天，次要「还想做？再来 5 题」最多取五道；先取积压，无积压时取未来三天内适合提前复习的题，排除当天已保存作答的题，重复进入不写记录、当天已做题数按题去重。撤销后恢复相应统计与出题资格。当天完成章旁显示连续复习天数；本组题目让知识点由未贴上变为已贴上时提示「新贴纸到手」。

原题展示不调用 AI；本地比对判对的题不调用 AI，其余判题使用现有配额与断线恢复机制。记录标记为 `source: "review"`，保存文字/手写/拍照作答、识别文本、思路和判题依据，不写变式字段。完整备份版本为 18，保留把握程度、作答时长、每日分钟数和最后一次手动调整；导入所有旧版（≤15）时按新规则重放。复习页从题目显示到提交累计前台用时，后台暂停，AI 判题与确认时间不计入；其他作答来源不写入时长。

在「设置 → 通用 → 复习」调整「每天复习多少分钟」，默认 30，10–180、步长 5。数学/物理/化学默认每题 4 分钟，英语 1 分钟，其他科及未识别学科 2 分钟；该用户同科最近 20 条有效前台用时（10 秒–30 分钟）至少有 5 条时，改用中位数。今日已做的 review 记录按估计值扣额度，而非实际用时；当天第一题即使超额也放行。未排入今日队列的题不展示，仍保留原到期日。积压超过三天额度时只轻提示一次，不显示数量。首页完成态显示「今天的错题清空啦」与日期「搞定」章及本日用时，提供「还想做？再来 5 题」：最多五道，先取积压；没有积压时取未来三天、已进入至少第三轮的题，排除当天已保存作答的题。

错题详情中的「复习安排」显示「第 N / M 轮」与下次日期，或「复习完成」。点「标记复习完成」退出日常复习，点「重新加入复习」从第一轮、明天开始。这两个操作不新增作答，也不改变 AI 掌握概率。之后的作答及其删除会保留最近手动调整的意图；调整之前补录的记录不会覆盖它。

复习安排由作答历史和最后一次手动调整重放得到，持久化日期用于快速查询。首次读取旧题时自动按用户、基线到期日顺序初始化并做最后一步负载选日，部署只需正式数据库迁移；可显式指定数据库运行 `DATABASE_URL="file:/绝对路径/目标.db" node --conditions=react-server scripts/backfill-review-state.cjs` 做幂等全量回填。新备份恢复到空库保留稳定 ID；遇到冲突或重复题合并，按目标题目重新计算日期。复习完成与「已掌握」是独立状态。

接口：`POST /api/practice/record` 接受可选的 confidence=sure/unsure；`GET/PUT /api/error-items/:id/review` 读取安排或以 action=completed/restart 手动调整，仅限本人错题。`GET /api/review/due?format=overview` 返回今日分钟队列的轻量摘要、科目、估计用时及额度字段；会话使用 `format=ids`，额外一组增加 `mode=extra`，不再使用 limit。`DELETE /api/review/undo?recordId=…` 仅接受本人一分钟内的最后一条复习来源记录，关联错题也必须属于本人；一分钟用于容纳提示结束前发起的请求延迟。校验、删除和调度重算在事务中完成，再触发掌握度重评估；旧版详情页的通用记录删除接口保持原语义。

## 生成错题试卷

1. 打开试卷入口，选择错题本、知识点、题型、掌握情况等范围，以及模式（举一反三 / 原题直出）。题型可不选（不限），也可多选只抽取指定题型的题目，含「未设置」（题型为空的题目）。
2. 系统从范围内抽取错题（默认"优先练习较少"：举一反三记录越少的题目越优先，练习次数相同时优先抽取从未出现在已有试卷中的题目，仍相同时随机；也可选"完全随机"）。
3. **举一反三**（默认）：由 AI 生成对应的变式题，在后台任务中查看生成状态，完成后打开试卷检查题干、图形和答案。可指定难度（简单/中等/困难/挑战）。
4. **原题直出**：直接使用原题的题干、答案、解析和配图组卷，不调用 AI、不消耗 AI 额度，创建后立即可打印。无需选择难度。
5. 打印或导出，完成后点「自己录入对错」进入批改结果页，逐题选「对 / 差一点 / 没做」。考试日期默认今天，可补录过去日期，不能选未来。全部判完后点「确认并保存」，结果才写入原题历史。

创建试卷时打开「同时生成 A/B 卷」，系统会按同样条件一次抽取最多 2×题量的互不重复题目，按题型与难度均衡分配为两份平行试卷：A 卷与 B 卷题目互不重复，题型分布与难度尽量接近，适合课堂测验或对比练习。标题自动加「（A 卷）」「（B 卷）」后缀；举一反三模式下两卷分别生成、各自消耗一次 AI 额度。源题不足两份时，若 B 卷至少能分到 1 题仍会创建两卷（B 卷题数可少于 A 卷）并提示题目不足；连 B 卷 1 题都没有时只创建 A 卷。

原题直出模式的试卷不显示"换一道题"按钮（原题不可更换），但仍可"重新生成解答"；录入结果时难度记为空。

试卷列表的状态依次为生成中、已生成（或部分失败、生成失败），录入过作答结果后显示为已完成。

试卷保留来源题目 ID，可据此回到原题。作答结果支持做对、做错和未作答；同一题可以保留多次结果，关联到原题的复习历史。

每道题可以单独设置分值（0～1000，最多一位小数，如 2.5），也可以用「每题统一分值」批量设置；留空表示未设分值。试卷顶部显示总分（只累加已设分值的题目，并注明有几题未设分值）。打印时题号后标注「（N 分）」，标题下显示「满分 N 分」；未设分值的试卷打印与旧版一致。分值随备份导出与导入。

试卷详情页可开启「按题型分大题」：开启后题目按题型分为选择题、填空题等大题（顺序为题型的默认顺序），大题标题行显示「共 N 题，共 X 分」（部分题未设分值时注明未设分值题数），题号全卷连续编号（跨大题递增）；打印与导出 HTML 同样按大题分组，大题标题加粗并带上下边框，适合黑白打印。创建试卷时系统快照来源错题的题型；旧试卷没有快照时按来源错题当前的题型分组，来源已删除或题型无法识别的题目归入「其他」。开关与题型快照随备份导出与导入（备份版本 11）。

## 学习统计

错题统计展示累计错题、还没掌握、已掌握数量、掌握率、学科分布和趋势图；练习统计单独展示练习次数、正确率、活跃天数，以及难度与学科分布。两个页签都支持按时间范围（近 7 天 / 近 30 天 / 近 6 个月 / 全部）和学科筛选。筛选某个学科后，点击还没掌握 / 已掌握卡片可直接跳转到该错题本中对应状态的错题列表（地址栏带 `?mastery=` 参数，错题列表按此参数预设筛选）。趋势图按粒度显示每日或月度，包含「新增」与「新掌握」两个系列：新增是每桶内创建的错题数，新掌握是最近一次掌握评估时间落在该桶内的已掌握错题数（近似口径，以最近一次评估时间作为掌握时间；这类错题可能创建于范围之前，因此不受创建时间范围限制）。对比两个系列可以直观看出错题本是在变少还是越积越多。错题统计页签在科目分布与趋势图下方还有「错因分布」卡片：上半部分按作答状态（不会做 / 做错了 / 未判断）展示环形图与占比，下半部分按错误类型展示横向条形列表（名称 + 数量 + 进度条），错误类型为自由文本，仅显示数量前 7 个，其余合并为「其他」；尚未填写错误类型时显示提示文案。统计同样受当前时间范围与学科筛选约束。错题统计页签在错因分布右侧还有「难度分布」卡片：按难度星级（1~5 星）展示每个难度的总错题数与已掌握数，已掌握部分以不同颜色叠加显示；未评定的错题也会单独列出。没有任何已评星错题时该卡片不显示。错题统计页签在概览与进度条下方展示同源收集册摘要与入口，按全部错题推算、仅跟随学科筛选，不受统计时间范围影响；旧 `/api/stats/weak-tags` 接口仍兼容旧客户端。练习统计页签顶部还有「学习日历」热力图，以 GitHub 风格方格展示最近 26 周每天的学习活动（录入错题 + 练习次数），并显示当前连续天数、最长连续天数和累计活跃天数；录入错题也算活动，所以没有练习记录时热力图也能显示。练习统计页签最下方还有「反复错题目」榜：列出所选范围内做错 2 次以上的题目 Top 10（含举一反三、试卷、手动录入与重复导入的做错记录），每行显示题干预览、学科、出错次数、最近出错日期和复习状态，点击可跳到对应错题详情，提示重点复习；没有数据时显示一句简短提示。

知识点也在统计中心：「知识点」页签顶部可切换标签体系（导入其他标签体系后显示切换器），按知识点汇总展示使用频率 Top 20（不同标签体系或学科的同名知识点分别计数），下方可浏览各学段学科的标准知识点并添加自定义标签，均按所选体系显示和添加。原 `/tags` 链接会自动跳转到这里。

日期和统计边界使用[应用时区](Settings-and-Users)。更改时区会影响按日或按月分组，但不会平移数据库中的时间。

### 收集册与连续复习天数

收集册按用户、学科、标签体系与知识点展示全部相关贴纸，稳定排序并支持状态筛选。全部错题已掌握显示「已贴上」；否则近 30 个应用日有效作答全对且至少一次显示「在好转」；其余显示「还差 n 题」，可进入该体系知识点的未掌握列表。没有题的标签不入册，撤销、删题与重标后重新推算。今天显示连续复习天数与可核实的「这周新贴纸」（周一为周首）；仅能确认首次掌握日期时列入，本版只确认单次有效作答且同日完成评估的知识点，其余仍可在收集册显示已贴上。首版连续天数按应用时区当天有至少一次有效复习作答近似计算，不含录入、跳过、手动调度、重复导入或举一反三加练；今天未复习保留截至昨天的连续数，并提示「今天复习后继续」。此口径独立于统计学习日历的活跃天数。仅派生现有数据，不新增数据表或修改备份格式。

## 试卷作答接口（备份第 18 版）

服务端已支持开始或继续一次作答、保存逐题文字与图片、小旗、累计用时、交卷、人工选结果、确认和放弃。每卷只保留一个未完成作答，跨方式开始也会复用。交卷前作答详情隐藏参考答案与解析。交卷后，本地比对一致的纯文字预填为对，空题预填没做，其余有作答且有参考答案的题交给后台 AI 判题，结果可人工修改。

确认时写入原题历史并同步复习安排，重新确认会替换同一次作答的记录。作答与历史共用按内容哈希保存的图片引用，解除最后一个引用后才可删除文件。试卷页的「自己录入对错」统一进入批改结果页；已有未完成作答时打开那一份。作答记录显示次序、日期、方式、做对题数和状态；题目卡片保留旧手动记录，新记录可点进对应作答。首次保存前的手动录入始终按题号平铺；其他作答只在载入或保存后计算分组与顺序，编辑时卡片位置固定。结果页头部和完成章使用本地化短日期。结果页实时统计题数，仅当每题都有分值时显示得分；未判题可点击剩余数量定位。确认后只读并盖「搞定」章，差一点的题可「去订正」，「改结果」后再次确认会替换本次记录。待确认作答可二次确认后放弃，已保存作答不可删除。图片、文字、AI 转写及依据只在有数据时展示。旧 `POST /api/exams/:id/results` 接口保持兼容。在线作答与后台批改见下节；整页拍照交卷见下文。

## 在线做卷与后台批改

在试卷页点「开始作答」，有未交的在线作答时显示「继续作答（已答 a/b）」。同一试卷只能有一份未完成作答；若已有其他方式的作答，先完成或放弃它。

作答与批改进度采用专注模式，隐藏全局导航。横屏宽度 ≥1024px 左题右答，较窄屏幕上题下答。题号按钮至少 44px，实心为已答、空心为没答、小旗为等会再看；窄屏点题号进度展开面板。键盘焦点不在输入框时可用左右方向键切题。交卷前不展示参考答案、解析或来源错题链接。

键盘、手写、拍照复用复习输入组件，支持续纸、专心写和 Pencil 设置。文字、可编辑笔迹与最多三张照片按作答和题目存入本机 IndexedDB，切题、刷新后可继续修改；不随个人备份导出。停笔两秒、切题、页面隐藏时自动保存，失败指数退避，联网后补传。服务器保存文字、合成展示图和最多四张判题原图。换设备没有笔迹数据时先只读展示服务器图片，可点「清空重写」。计时只累计前台作答时间，可隐藏，累计用时随保存上传。

交卷先等待保存，再确认已答、没答和小旗；题号可返回检查。触摸交卷沿用书写中及抬笔后 800ms 防误触。确认交卷后不能撤回。纯文字确定匹配先本地判对，其余有作答和参考答案的题后台批改，同时最多三题。整卷计一次每日 AI 次数，token 按实际记录；额度不足直接进入结果页，提示自行对答案。失败或服务重启中断不会自动重判，可在结果页「重新批改这题」，每题最多两次、不再计次数，token 仍记录。今天页显示批改中和待确认的提醒。

结果页可回看「我写的」图片、文字、折叠 AI 转写与判题依据，AI 判断只是预填；「确认并保存」才写入学习记录并影响复习。确认后清空判题原图并回收无引用文件，保留展示图。完整备份升级为第 18 版，包含判题原图与重判次数，兼容第 17 版及更早备份。整页拍照交卷见拍照交卷部分。

作答页在宽屏将题号图例放在题号条右侧，窄屏仅在展开题号面板时显示；打字区在可用视口内滚动，底栏不遮挡答案。结果页用时不足一分钟只显示秒数，未判出的题只显示一句原因及可用的重新批改入口。

### 拍照交卷

纸上完成后，在试卷页点“拍照交卷”。一页一张，最多 8 张，可排序、旋转、重拍、删除。照片逐张上传，交卷后后台定位与批改，整卷计 1 次额度。看不清或卷号不符的页返回重拍，仅重新定位变化页。红笔覆盖至少一半原题时按红笔预填，与 AI 冲突的题要看一眼。没找到作答可选没做、补拍这一题或自行选对错。确认保存后仍可看整页及作答区域，临时多图判题素材清理。 卷号同长度时容错 1 个字符。问题页可点“就用这几张，继续批改”，复用定位与整卷额度；看不清的页按没找到作答处理，卷号不符的页继续使用定位结果。定位失败提示“批改没能开始，再试一次”，可“重新交卷”或“自己录入对错”；后者逐题保留“还没判”，整页照片仍可翻看。

### 做题记录

从「我的」学习区第一行进入 `/history`。今天页的连续天数印章、收工页的「看看今天的记录」、学习日历点选后的「查看这天」，以及原题复习摘要中每次作答的日期，也能进入记录页。学习日历的小结仍使用原有录入与练习活动口径，进入记录页后只统计有效作答。

周条从周一开始：空心表示没做、实心表示做了、带勾表示当天全对；今天有文字标记。左右箭头换周，点月份标题展开月历，可回看更早日期；不能选未来日期。选天后先展示当天，再加载更早记录。每次读取七天窗口，空窗口沿用接口跳到最近的更早记录，直到没有更早记录。

紧凑周条的「回到今天」位于月份标题右侧，仅在所选日期不是今天或浏览的周不含今天时出现。当天小结与列表使用相同的本地化日期；详情时间省略年份，用时不足一分钟仅显示秒数，满一分钟显示分与秒。题干预览在 120 字边界截断并加「…」，边界落在公式内时回退到公式前。

学科使用「全部 + 单科」贴纸筛选，可开启「只看差一点」；竖屏平板和手机从「筛选」按钮展开。筛选与日期、记录选择都保存在 URL（`date`、`record`、`subjectId`、`result=wrong`），刷新或分享站内链接可保留选择。日历圆点不受对错筛选影响。

每日按复习、再来一道类似的、试卷、手动录入分组，试卷按卷折叠，可展开或打开试卷。小结显示作答次数、做对次数和实际保存的复习用时；试卷「没做」为灰色，不计作答次数。点记录查看题目、当时作答、可折叠的 AI 转写与参考答案、判题依据和把握程度。配图与作答图片可放大，有原题时可「打开原题」。记录页只读，不提供删除或更正；更正仍在原题或试卷页进行。

横屏平板（宽度 ≥1024px）左列表右详情，详情贴近视口顶部，长内容在栏内滚动；未选记录时显示当天学科小结。详情加载时也可点「关闭」取消选中，回到当天小结。窄屏为底部面板，关闭保留列表位置；支持手账、简洁与深色界面。加载时显示骨架，失败可重试；空日、筛选为空与从未作答分别提示。

### 做题记录只读接口

接口仅返回当前用户的 `review`、`practice`、`exam`、`manual` 记录，排除重复导入与未判定记录。`result` 优先，旧记录为空时回退到 `isCorrect`；`not_attempted` 保留在列表里但不计入作答次数。日期按应用时区计算。

| 接口 | 参数与响应 |
| --- | --- |
| `GET /api/practice/history` | `before=YYYY-MM-DD` 为不含当天的上界，默认明天；`days=1–31` 默认 7。可选 `subjectId`、`result=wrong`；`date=YYYY-MM-DD` 优先，只取当天。返回 `{ days: [{ date, summary, records }], nextBefore, hasMore }`，日期倒序、日内时间正序。空窗口直接跳到最近的更早记录所在窗口；指定 `date` 时保留空日结果。`nextBefore` 为下一窗口的排他上界，末页为 `null`。 |
| `GET /api/practice/history/calendar?from=&to=` | 首尾日期均包含，最多 62 天；支持 `subjectId`。返回 `{ days: [{ date, total, correct }] }`，无记录日期补零。 |
| `GET /api/practice/record/:id` | 返回题目、配图、答案、解析、当次作答、AI 转写、判题依据、用时与试卷关联。他人或不存在的记录返回 404。原题复习与手动记录读取当前原题；类似题与试卷读取记录快照。本地作答图片使用 `/api/error-items/:id/image?record=&field=answer`。 |

`summary` 包含 `total`、`correct`、`wrong`、`notAttempted` 和仅累计复习时长的 `reviewDurationSec`。日历不受“只看差一点”筛选影响。无效日期、区间或不属于当前用户的 `subjectId` 返回 400。现有 `DELETE /api/practice/record/:id` 继续用于原有更正流程。
