# 错题本与复习界面改版（设计稿）

状态：方向已确认（2026-11-09），待拆分实现。本文覆盖错题本列表、错题详情、复习首页、复习作答与对照五个画面（核对相关画面的效果图也列在第 12 节），取代之前的 `REVIEW_CARD_UI.md` 草稿。题目出处与核对见 `QUESTION_INTEGRITY.md`，其中的核对卡片沿用本文的卡片样式。

## 1. 设计原则

1. **一屏只做一件事。** 每个画面只保留完成主要任务需要的元素，其余收进“更多”菜单或折叠。
2. **少即是整齐。** 一个页面最多一个主按钮；标签、徽章、色条只在表达有用信息时出现。
3. **内容优先于工具。** 题目文字、原图、答案放在最显眼的位置；编辑、AI 工具、管理操作退到二级入口。
4. **同一种东西长得一样。** 全站统一卡片、元信息行、答案对照块、“更多”菜单和编辑方式。
5. **移动优先。** 手机竖屏为基准，iPad 横屏和桌面在此基础上加宽或分栏。

## 2. 现状问题（来自 2026-11-09 本地截图）

截图含真实学生作业，不入库。

### 错题本列表
- 顶部 3 个按钮（删除、重新识别知识点和难度、添加错题）+ 工具栏 4 个按钮（筛选、导出打印、比较相似度、多选）+ 3 个下拉框 + 4 个卷别标签 + 11 个题型标签，未开始看题就有 25 个控件。
- 卡片只显示题干第一行。语文字音题全部显示“根据拼音写出括号里的汉字。”，十几张卡片完全一样，分不出是哪道题。
- 每张卡片都有“待复习”徽章、短编号、日期、“做错了”标签、知识点标签和彩色左边框。“做错了”对错题本里的每道题都成立，属于无效信息。

### 错题详情
- 页面由约 10 张卡片组成：题目、复习安排、掌握概率、参考答案、错误解答、解析、错因分析、SVG 动画、GeoGebra、笔记；按钮超过 15 个，每张卡各有“编辑”。
- 顶部同时有短编号、星级、举一反三、复习状态、删除、报告问题。
- 原图藏在“查看原题图片”按钮里，与“替换原题图片”“AI 重新生成配图”并列。
- 空的 SVG 动画、GeoGebra 占位区块常驻。

### 复习
- 作答：题目卡和作答卡分成两块；“键盘 / 手写”是两个大按钮；输入框固定高度；“+ 写解题思路”是一行灰字。
- 对照：手机上“这次”和“上次错答”左右并排，窄列文字逐字折行，卡片高度被撑得很长；三个判定按钮排成 2+1，右侧“对，有把握”与下方“做错了”不对齐。
- 复习首页整体较好，“只复习某一科”与上方科目列表重复。

## 3. 统一的界面元素

| 元素 | 规格 |
| --- | --- |
| 页面背景 | 浅灰（`bg-muted/40`） |
| 卡片 | 白底、12px 圆角、细边框、极浅阴影；内边距手机 16px、桌面 24px |
| 题目正文 | 17px，行高 1.75 |
| 元信息行 | 13px 灰字，用“·”分隔：`填空题 · 七年级上 · ★★` |
| 状态 | 只用小圆点 + 文字：待复习（橙）、已掌握（绿）、需要看一眼（黄）。不用大徽章，不用彩色左边框 |
| 原图缩略图 | 圆角 8px；点开为整页并框出题目位置（见 `QUESTION_INTEGRITY.md`）。原图上常有学生作答和老师批改，凡是“先作答、后看答案”的画面（复习作答、举一反三），作答前都不显示原图 |
| 答案对照块 | 竖排三行：你的答案 / 上次错答 / 标准答案，每行左侧 3px 色条（蓝 / 红 / 绿），标签列固定宽度 |
| 更多菜单 | 右上角“⋯”，放低频和危险操作 |
| 主按钮 | 每屏最多一个，实心主色；其余为描边或文字按钮 |

### 4.1 布局（手机）

```
←  小明·语文                    ⋯
   24 道 · 待复习 18

[🔍 搜索题目或知识点        ] [筛选]
 全部   待复习   已掌握              ← 分段切换

11月9日 · 语文七年级上.pdf · 15 道
┌────────────────────────────────┐
│ kěn（　）求                [图] │  ← 显示题目的关键内容
│ 字音字形 · 待复习 ●             │
├────────────────────────────────┤
│ 花团 jǐn cù（　　）        [图] │
│ 字音字形 · 待复习 ●             │
├────────────────────────────────┤
│ 补写《诫子书》：淫慢则不能励精，… │
│ 古诗文默写 · 待复习 ●       [图] │
└────────────────────────────────┘
11月7日 · 拍照导入 · 3 道
…
                          [+ 添加]   ← 右下角悬浮按钮
```

### 4.2 要点

- **标题区**：错题本名称、题数、待复习数；右上“⋯”菜单收纳：导出打印、多选、比较相似度、重新识别知识点和难度、重命名、删除错题本。
- **筛选**：只保留一个搜索框、一个“筛选”按钮和三段状态切换。年级、章节、知识点、卷别、题型都放进筛选面板（手机为底部弹出，桌面为右侧弹出）；生效的条件以可删除的小标签显示在搜索框下方，没有条件时不占位置。
- **列表**：用分隔线的列表代替卡片网格，信息密度更高、更整齐。每行：
  - 题目预览：去掉同批题目共有的题型说明（如“根据拼音写出括号里的汉字。”），显示题目自己的内容；最多两行。
  - 右侧原图缩略图（56×56），没有原图则不显示。
  - 元信息行：第一个知识点 · 状态。去掉短编号、日期（日期改由分组标题表达）和“做错了”标签。
- **分组**：按导入批次分组，组标题为“日期 · 来源 · 题数”，与题目出处对应。
- **多选**：从“⋯”菜单进入，或长按一行进入；底部出现操作栏（导出、移动、删除）。
- **添加**：右下角悬浮按钮，桌面为标题区右侧的主按钮。

### 4.3 桌面

内容区最大宽度 960px，仍为单列列表，每行加宽，元信息与缩略图同一行；筛选面板从右侧滑出。不再使用三列卡片网格。

## 5. 错题详情

### 5.1 布局（手机）

```
←                         ⋯
┌────────────────────────────────┐
│ 填空题 · 七年级上 · ★★         │
│                                │
│ 《诫子书》题解填空。             │
│ “诫”本来的意思是什么？           │
│                                │
│ [原图缩略图，点开看整页]         │
│ 来自 语文七年级上.pdf · 第 7 页   │
│                                │
│ #文言文阅读                      │
└────────────────────────────────┘
┌────────────────────────────────┐
│ ▌我的错答   劝告、提醒           │
│ ▌正确答案   用话语使人警觉、清醒。 │
└────────────────────────────────┘
 解析 | 错因 | 笔记                  ← 分段切换，默认“解析”
┌────────────────────────────────┐
│ 本卷红笔和蓝笔订正均要求写出…     │
└────────────────────────────────┘
复习 · 第 1/5 轮 · 下次 11月10日   ›   ← 一行，点开看详情
[        举一反三        ]            ← 底部主按钮
```

### 5.2 要点

- **顶部**只保留返回和“⋯”。“⋯”菜单：编辑、替换原图、重新生成解答、修正公式、生成动画讲解、GeoGebra 演示、复制编号、报告问题、删除。
- **题目卡**：元信息行（题型 · 年级 · 难度星）→ 题目正文 → 配图 → 原图缩略图与出处 → 知识点标签。“试题信息”表格取消，错题本、卷别等低频信息放进编辑模式。
- **答案对照块**：我的错答与正确答案放在一起，样式与复习对照一致。没有错答时只显示正确答案。
- **解析 / 错因 / 笔记**合并为一张卡，用分段切换；某一项为空时仍可切换，内容显示“暂无，点编辑补充”。
- **复习与掌握**合并为一行摘要，点开为底部弹出面板：复习轮次、下次时间、掌握概率、举一反三记录，以及“标记复习完成 / 重新加入复习”。
- **AI 生成内容**（动画讲解、GeoGebra）：已生成时显示在解析下方；未生成时不占位置，入口在“⋯”菜单。
- **编辑**：一个“编辑”模式代替各卡片的单独编辑按钮。进入后所有字段同时可编辑（题目、答案、错答、解析、错因、笔记、题型、年级、错题本、卷别、知识点、难度），底部出现“保存 / 取消”。
- **主按钮**：底部固定“举一反三”。

### 5.3 桌面

两栏：左栏（60%）题目卡 + 答案对照 + 解析卡；右栏（40%）原图大图（整页框选）+ 复习摘要 + 举一反三按钮。顶部仍只有返回和“⋯”。

## 7. 复习作答

### 7.1 布局（手机）

```
×        数学 · 1 / 17         跳过
━━━━━━─────────────────────────────
┌────────────────────────────────┐
│ 解答题 · 错过 1 次               │
│                                │
│ 对于有理数 a、b、c，我们称       │
│ |a−c|−|b−c| 为 a、b 到 c 的…     │
│ (1) −1、2 到 4 的“行程差”…       │
│ (2) …                          │
│ (3) …                          │
│ ────────────────────────────── │
│ [ 打字 | 手写 ]                  │
│ ┌────────────────────────────┐ │
│ │ 写下你的答案                 │ │  ← 随内容自动增高
│ └────────────────────────────┘ │
│ ✎ 写思路                        │
└────────────────────────────────┘
[            提交            ]
```

### 7.2 要点

- 题目和作答在**同一张卡片**里，以分隔线分开；题目不再限高、不在卡内滚动，只有页面一层滚动。
- **作答阶段不显示原图。** 原图上常有学生当时的作答、老师的红笔批改甚至正确答案，提前显示等于泄露答案。题目所需的图形用配图（重绘的 SVG）显示。
- 例外：题目引用了图形（“如图”）但没有配图时，在题干下方显示一个按钮“查看原图（可能含答案）”，点了才显示，不自动展开。
- 分段控件“打字 | 手写”代替两个大按钮；已有内容的一侧显示小圆点。
- 输入框初始 3 行，随内容增高；手写画布占满作答区宽度，工具栏浮在画布右下角。
- “写思路”为图标文字按钮，点开在输入框下方展开小文本框。
- 底部只有“提交”。答案为空时点击，输入框下方提示“先写下答案”。
- 桌面 `⌘/Ctrl + Enter` 提交。

### 7.3 iPad 横屏 / 桌面

同一张卡片内左右分栏：左 45% 题目与配图，右 55% 作答；提交按钮在右栏底部。作答阶段同样不显示原图，提交后左栏题目下方出现原图。

## 8. 复习对照（提交后）

### 8.1 布局（手机）

```
×        数学 · 1 / 17
━━━━━━─────────────────────────────
┌────────────────────────────────┐
│ 对于有理数 a、b、c，我们称…  ⌄   │  ← 题目折叠为两行，可展开
│ ────────────────────────────── │
│ ○ 请自己核对                     │  ← 状态行：AI 判定 / 本地判定 / 自己核对
│ ────────────────────────────── │
│ ▌你的答案   x+y=2，最小值为 1     │
│ ▌上次错答   (1) 3；(2) 写成 x+(1−x)=1…│
│ ▌标准答案   (1) 3；(2) x+y=2；(3) 1 │
│ ────────────────────────────── │
│ › 原图                           │  ← 提交后才出现，点开看整页与框选
│ › 详细解析                       │
└────────────────────────────────┘
[ 做错了 ] [ 对，不确定 ] [ 对，有把握 ]   ← 一行三等宽
```

### 8.2 要点

- 卡片原地切换为对照状态，不跳页面；题目折叠为两行摘要。
- 状态行一行文字加小图标：AI 判对（绿）、AI 判错（红）、正在核对（转圈）、请自己核对（灰）。AI 理由点开再看。
- 三行对照竖排，每行占满宽度，解决手机上左右并排逐字折行的问题。手写作答显示缩略图。
- 原图、详细解析、举一反三为折叠行。原图默认收起，想核对时点开，显示整页与题目框选。
- 若这道题有待处理的核对问题（见 `QUESTION_INTEGRITY.md`），原图行显示为“这道题可能与原图不一致 · 看原图”。
- 判定按钮一行三个等宽：“做错了 / 对，不确定 / 对，有把握”。AI 有建议时，建议的那一个为实心，其余描边。去掉“选一个，自动进入下一题”说明。
- 桌面可按 1 / 2 / 3 快捷判定。
- 判定后卡片滑出，下一张滑入；系统开启“减少动态效果”时直接切换。

## 13. 已确认的决定（2026-11-09）

1. 错题本列表改为单列列表，按导入批次分组，去掉短编号和日期；短编号在详情页“⋯ → 复制编号”取得。
2. 错题详情底部主按钮为“举一反三”。
3. 复习作答阶段不显示原图，提交后的对照阶段可展开查看（原图常带作答与批改）。
