# Codex 与 Claude Code 协作

两个工具在同一个项目目录使用相同的源码、文档和运行环境。聊天记录、自动记忆、插件、登录状态和工具权限由各工具分别管理；需要接续的项目事实写入共享文件。

## 文件入口

| 文件 | 用途 | 是否进入 Git |
| --- | --- | --- |
| `AGENTS.md` | 共享开发规则与上下文入口 | 是 |
| `CLAUDE.md` | 用 `@AGENTS.md` 为 Claude Code 导入共享规则 | 是 |
| `doc/AGENT_COLLABORATION.md` | 协作、核验与交接流程 | 是 |
| `data/operations/README.md` | 本机当前状态：部署说明、检查快照、待办与最近交接 | 否 |
| `data/operations/history/` | 按月归档的完整交接记录，按需读取 | 否 |
| `CLAUDE.local.md` | 用 `@data/operations/README.md` 为 Claude Code 导入本机说明 | 否 |

Codex 从 `AGENTS.md` 读取入口指引；Claude Code 通过 `CLAUDE.md` 导入同一文件。本机说明使用普通 Markdown，两个工具均可直接读取，不依赖某个工具的记忆目录。

`data/` 被 Git 忽略，文件搜索工具可能跳过它；请直接读取 `data/operations/README.md`。本机说明是环境记录，运行状态仍需实时核查。

## 开始与接续任务

1. 在同一个 Git 工作副本中打开项目，读取共享规则和已有的本机说明。
2. 用 `git status --short --branch`、`git diff` 和最近提交确认已有工作；保留另一会话的修改和暂存状态。
3. 查询部署状态时，分别确认源码提交、远端提交和运行服务的 `/api/health`；记录检查时间。远端跟踪引用可能过期，确认远端当前状态时使用 `git ls-remote` 等只读操作。
4. 缺少本机说明时，从服务管理器、启动配置、监听端口与健康接口只读核查。仅提取必要的非敏感字段，避免完整打印环境变量、配置文件或令牌。
5. 同一文件、数据库迁移和服务部署依次操作。构建产物属于运行环境的一部分，构建前先确认是否被当前生产服务使用。

## 本机上下文初始化

在需要共享本机运行信息的工作副本中创建 `data/operations/README.md`，记录：

- 主机、项目目录、服务管理方式、程序入口与监听地址。
- 数据库、图片、配置、日志和备份的位置，不记录凭据内容。
- 内外网入口和转发关系，以及每条关系的核查依据。
- 带检查时间的运行版本、源码提交与远端核验结果。
- 当前任务的改动、验证结果、提交/推送/部署状态和待办。

若没有 `CLAUDE.local.md`，可创建它并只写一行 `@data/operations/README.md`。该文件已被 Git 忽略；已有文件则保留内容并补充导入。跨机器使用时，需要单独建立对应机器的运行说明。

## 交接格式

本机说明只保留当前状态、未完成待办和最近 2 条交接，控制在约 8 KB，避免每次会话加载大量历史。完整记录按月追加到 `data/operations/history/<年-月>.md`。仍未完成的事项移到待办清单，完成后删除。每条记录格式：

```markdown
### 检查时间：YYYY-MM-DD HH:mm，注明时区

- 任务与改动：
- 验证结果：写明执行过的检查及其结果。
- 源码：当前提交、未提交改动。
- 远端：核查方式与结果；未核查时注明。
- 运行服务：健康接口返回的版本与 revision；未取得时注明。
- 交付状态：是否提交、推送、部署。
- 待办与已知限制：
```

涉及代码的约定、架构和通用流程应写入可公开的项目文档。私有运行信息留在 `data/operations/`，凭据保留在既有受保护配置中。

## 验证入口

修改后，在项目目录新开会话。Claude Code 可用 `/memory` 检查加载的文件；较新版本也可用 `/context all`。确认能看到 `CLAUDE.md`、共享规则以及本机入口，再要求其只读回答服务入口和健康检查方式。Codex 同样需要确认本机说明已读取。

这套入口共享项目上下文；各工具的插件、MCP、授权和系统权限仍按各自配置生效。部署、推送等操作按 `AGENTS.md` 和用户当前授权执行。

官方机制说明：[Codex 项目指令](https://learn.chatgpt.com/docs/agent-configuration/agents-md)、[Claude Code 项目记忆与文件导入](https://code.claude.com/docs/en/memory)。
