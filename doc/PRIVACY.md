# 隐私说明

[English](PRIVACY.en.md) · 更新日期：2026-11-10

## 适用范围与存储

wrong-notebook 是可自托管的错题本软件。桌面版在本机运行服务端；Docker、npm、飞牛OS 和源码部署的数据由相应实例的运营者管理；安卓客户端连接用户指定的实例。请按实际部署方式了解谁可以访问该实例的数据。

实例会保存使用功能所需的账号信息、密码哈希、题目文字与图片、答案、练习和试卷记录，以及个人偏好。数据库、上传文件、服务日志及配置保存在该实例的数据或配置目录；各平台路径见[安装包说明](INSTALL_PACKAGES.md)。浏览器诊断日志可能包含页面地址、浏览器标识、错误信息和操作上下文，并发送到同一实例的服务端。它们不会因此自动发送到项目维护者的服务器。

文字和直接录入草稿会按账号与错题本保存在当前浏览器标签页的会话存储中，刷新可恢复；清空草稿、退出登录或注销账号会清除相应内容。草稿不进入个人备份，也不会自动发送给 AI；浏览器禁用会话存储时仅在当前页面内保留。文件选择与解析摘要仅在当前页面保留，刷新需重新选择文件。

AI API Key、服务地址，以及用户主动连接 MiniMax Code 后的登录凭据保存在实例配置中。MiniMax Code 的 access token、refresh token、账号资料和签到结果保存在配置目录的 `minimax-code.json`。请妥善管理实例访问权限、配置和备份。

手写作答的向量草稿仅在当前页面内存中保留，浏览器仅额外记住是否检测到过笔输入以默认开启防误触。确认练习结果后，手写答案图片和 AI 识别文本保存在实例中，并包含在个人完整备份内。

拍照作答的照片仅在当前作答的内存中保留，换题或刷新会清空。自评确认后，裁剪压缩后的照片与手写图竖向拼成展示图保存在实例中，并包含在个人完整备份内。摄像头只在用户点「拍一张」时由系统调起，应用不申请常驻权限。

试卷在线作答的文字、可编辑笔迹与裁剪压缩照片按作答和题目保存在本机浏览器 IndexedDB，刷新或离线后仍可继续；交卷成功后清除这一份本机草稿，本机草稿不进入个人备份。试卷作答展示图及最多四张判题原图会上传并保存在服务器，判题时连同题目、参考答案、解析和作答文字发送给所配置的 AI 提供商，仍需同意 AI 数据授权。确认保存后删除无引用的判题原图，保留用于回看的展示图；服务器图片随完整备份导出。整页拍照交卷另行提供。

## 第三方服务

- 使用传统复习提醒渠道时，待复习数量和科目会发送到你选择的第三方推送服务，并在配置站点地址时附带复习页链接；不发送题目正文、图片或答案。传统渠道的推送凭据保存在实例数据库，并会进入用户的明文导出备份。Apple 设备通知只发送通用复习提示，Apple 负责向设备投递。设备订阅地址、加密参数和投递记录留在实例数据库，个人导出只保留渠道、时间及最近结果。关闭提醒会停止后续自动推送，不影响第三方已收到的数据。
- 使用 AI 识别、解答、生成练习、动画等功能时，会将任务所需的题目、图片、答案或提示词发送给管理员配置的 AI 服务商及接口。每个账号首次使用前会看到「AI 数据授权」说明，列出发送的数据和当前服务商，**同意后才会发送**；不同意时 AI 功能不可用（掌握程度改按规则估算），其他功能照常使用。授权可随时在「设置 → 账户」中撤回，撤回不影响已发送给服务商的数据。
- 导入后自动图文核对默认开启：账号同意 AI 数据授权后，网页或代理导入的题图、出处页缩略图（标出题目区域）、题干、标准答案及学生错答会发送给服务端配置的 AI 服务，用于检查原图与保存文字是否一致。修改相关内容会重新核对；纯文字题不执行。管理员可在「设置 → AI 设置」关闭「导入后自动检查题目与原图是否一致」停止后续自动核对；关闭不影响服务商已接收的数据。
- 拍照作答的照片在本机裁剪压缩后，与手写图片一样发送给所配置的 AI 提供商；照片原图不上传、不保存。

试卷“拍照交卷”的整页照片会在本机压缩后上传并保存在服务器，用于定位、裁剪和回看，并发送给所配置的 AI 提供商。确认保存后清理临时判题图片，整页照片与首张作答展示图保留；删除试卷或放弃作答时回收无引用照片。该流程与单题拍照作答“照片原图不上传、不保存”的处理不同。

- 原题复习和举一反三提交手写答案判题时，裁剪压缩后的手写图片会与题目、标准答案及可选文字答案一起发送给所配置的 AI 提供商及接口，用于识别与判题；遵循同一 AI 数据授权。撤回授权或删除本地记录不影响提供商已收到的数据。
- 使用云端语音时，讲解文字会发送给所配置的语音服务商；浏览器语音使用浏览器提供的能力，其处理方式取决于浏览器和所选声音。
- 主动登录 MiniMax Code 后，登录、令牌刷新与 AI 请求会连接 MiniMax 服务；自动签到功能也会定期向 MiniMax 发送该账号的签到请求。不使用该集成时无需连接账号，可在设置中退出登录。
- 打开文档或项目链接会访问 GitHub 等第三方网站，由对应服务按其隐私政策处理访问请求。

第三方对请求的保存、使用和处理以所选服务的条款为准。常见服务的隐私说明：[Google](https://policies.google.com/privacy)、[OpenAI](https://openai.com/policies/privacy-policy/)、[Anthropic](https://www.anthropic.com/legal/privacy)、[Microsoft](https://privacy.microsoft.com/privacystatement)、[GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)；其他 AI 渠道及自定义接口请参阅对应服务商的隐私政策。

## 数据管理与联系

用户可在实例中删除题目和学习记录、导出个人数据，普通用户还可在「设置 → 危险」中输入密码注销账号，账号及名下全部数据随之永久删除（管理员账号不能自助注销）；实例管理员负责账号、数据库、上传文件、日志及备份的保管和清理。卸载桌面版不会自动删除数据目录；安卓单机版卸载会删除其私有数据目录。删除实例中的数据不等于删除已导出的备份或第三方已收到的请求，应分别向相应运营者处理。

自托管实例的隐私请求请联系该实例管理员。软件本身的问题可通过项目 [Issues](https://github.com/shuiguojiao/wrong-notebook/issues) 联系维护者；涉及密钥、账号或漏洞的内容请使用[安全报告渠道](../SECURITY.md)，不要公开个人资料或凭据。


## 主动提交的问题反馈

你主动提交的问题反馈及题目快照对管理员可见。快照包含题干、答案、解析、知识点、科目、年级、录入方式与来源，以及有可靠关联时的录入 AI 提供商和模型；不复制原图内容或图片地址，只记录是否有原图。提交前会在弹窗提示共享范围，请勿在说明中填写敏感资料。管理员可标记处理状态并填写对提交人可见的备注；反馈列表不提供跳转查看用户完整错题本的能力。删除原题后报告及快照仍保留，注销账号时随账号删除。报告和管理员回复包含在用户个人备份中，请妥善保管；导入备份中的回复属于恢复记录，不代表管理员在当前实例重新审核。
