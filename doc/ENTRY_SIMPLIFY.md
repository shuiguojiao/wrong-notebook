# 录入入口与 AI 助手接入精简设计

状态：设计稿，待确认。不涉及 Prisma 迁移与备份格式。

## 1. “又错了新题？”录入入口

### 1.1 现状：同一件事有三层按钮

以 iPad / 手机（触屏）上的今天页为例，点开“拍照”后屏幕上同时出现：

| 层 | 来源 | 按钮 |
| --- | --- | --- |
| ① 今天页入口 | `student/today-entry.tsx` | 拍照 · 相册 · 更多▾（文字 / 文件 / AI Agent） |
| ② 录入面板切换 | `question-entry/entry-panels.tsx` 的 `SegmentedControl` | 图片 · 文字 · 文件 · AI Agent |
| ③ 图片上传区 | `upload-zone/image-source-buttons.tsx` | 拍照 · 相册 · 文件；拖放区；粘贴 · 截图 |

问题：

- “拍照”“相册”各出现 2 次，“文件”出现 3 次；
- 两个“文件”含义不同：③ 里的“文件”是挑一张**图片文件**，② 里的“文件”是导入 **PDF / Word / Excel 题库**，学生分不清；
- 点 ① 的“拍照”不会直接打开相机，还要在 ③ 再点一次“拍照”——多一步；
- “AI Agent”是给家长/老师配置用的，和学生日常拍题并列，太显眼。

### 1.2 方案：一排入口，点了就做

只保留一排四个入口，入口本身就是切换器，删除 ② 和 ③ 的按钮行：

```
又错了新题？
┌────────┬────────┬────────┬────────┐
│ 📷 拍照 │ 🖼 相册 │ 📄 文件 │ ✏️ 打字 │
└────────┴────────┴────────┴────────┘
        用 AI 助手批量导入 ›          ← 小号文字链接
```

| 入口 | 点击后 | 说明 |
| --- | --- | --- |
| 拍照 | **直接打开相机**（`capture` 选择器），拍完进裁剪 | 点击本身是用户手势，可以直接 `input.click()` |
| 相册 | 直接打开相册多选，选完走现有“单题/多页”询问 | 合并原 ① ③ 两个相册 |
| 文件 | 一个选择器，同时接受图片与 PDF、Word、Excel、CSV、TXT/MD、JSON；**按文件类型自动分流**：图片 → 图片识别；其他 → 现有文件导入面板 | 合并原 ② 的“文件”与 ③ 的“文件” |
| 打字 | 展开文字面板（AI 解题 / 我有答案，保持现状） | 原“更多 → 文字” |

其余：

- **桌面（精确指针）**：电脑上相册和文件是同一个系统对话框，四格合成两块——一个拖放区“拖入、粘贴或点击选择图片 / 文件”（点击走通用文件选择器，同样按类型分流）+“打字”按钮；粘贴（⌘V / Ctrl+V）在录入区全局可用，截图按钮只在支持的浏览器以小号文字按钮出现在拖放区内。
- **拍完一题后**：保留现有“继续拍下一题”主按钮（`canContinueCamera`），以及“看识别结果”链接；不再重复显示四格以外的来源按钮。
- **AI 助手**：从并列入口降为四格下方的小号链接，打开第 2 节的“AI 助手”页（同一组件，弹层或 `/me#agent-settings`）。
- **错题本内添加页**（`/notebooks/[id]/add`）复用同一排入口组件，不再显示分段控件。
- 去掉“更多▾”菜单——四个入口都可见，就没有需要藏起来的了。

### 1.3 实现要点

- 新建 `question-entry/entry-sources.tsx`：四格按钮 + 三个隐藏 `input`（相机、相册、通用文件），从 `upload-zone` 上移；`UploadZone` 只剩拖放区、粘贴和“继续拍下一题”。
- 通用文件 `accept`：`image/*` 加上 `src/lib/import/file-read.ts` 的扩展名列表；选中后按 MIME/扩展名分流到 `flow.selectImage(s)` 或 `FileImportPanel.importFile`（已有 `ref`）。
- `EntryPanels` 新增 `hideSwitcher`（或直接移除 `SegmentedControl`）；`EntryMode` 去掉 `"agent"`。
- 双击防抖：识别中（`isBusy`）四格禁用，和现在一致。
- 测试：`today-entry`、`upload-zone` 单测与 E2E 选择器（`image-sources`、`today-entry-actions`）同步更新；新增“文件选择 PDF → 进入文件导入”“文件选择 JPG → 进入裁剪”两条用例。

## 2. AI 助手接入页

### 2.1 现状

`question-entry/agent/agent-guide.tsx` 共 5 块：选客户端下拉 + 每种客户端的配置片段、创建令牌（要先起名）、连接状态、Skill（版本、下载 zip、更新命令）、示例指令。设置页 `agent-integration-settings.tsx` 又有一套几乎相同的内容。实际上 `agentSetupPrompt()` 已经能让 AI 自己判断客户端、改配置、装 Skill——手动配置片段和 Skill 区块对大多数用户是多余的。

### 2.2 方案：三步一页

```
AI 助手接入                               ● 已连接 · 2 分钟前
───────────────────────────────────────────────────────────
① 复制这段话，发给你的 AI 助手
   ┌─────────────────────────────────────────────┐
   │ 请帮我把错题本（https://…）接入你自己……      │  (默认折叠 3 行，可展开)
   └─────────────────────────────────────────────┘
   [ 复制提示词 ]   支持 Codex、Claude Code、Cursor、WorkBuddy 等

② 你的 Key
   [ 生成 Key ]  →  wnb_xxxxxxxxxxxx   [ 复制 ]
   只显示这一次。复制后连同提示词一起发给 AI 助手。

③ 试试这样说                                      (点一下复制)
   📷 用 $wrong-notebook-import 把这张试卷里打叉的题录入〈数学〉，先和我确认
   📚 把这个 PDF 练习册的第 3 章录入错题本，按题拆开并打上知识点
   🔍 帮我查最近一周录入的几何错题，按知识点归类
   🧩 这道题我录过吗？查一下重复
   ✏️ 把题号 7CFw66 的参考答案改成 x = 3
   🖼 给最近录入的题补上试卷原图出处

▸ 高级：手动配置、Skill 下载与更新、管理 Key（撤销）
```

要点：

- **① 提示词是主角**：一个按钮复制，不再先选客户端——提示词本身要求 AI 判断自己是哪个客户端（现有第 1 步）。预览默认折叠，想看的人可展开。
- **② Key 一键生成**：不再要求先填名称，默认名“AI 助手 · 11月11日”，不设到期时间。已有有效 Key 时显示“已有 2 个 Key，可直接用”，按钮变次要样式。
- **连接状态并入标题右侧**：灰点“等待 AI 助手连接” → 绿点“已连接 · N 分钟前”，每 15 秒刷新（现有逻辑），不再单独占一块、不再需要手动“刷新”按钮。
- **③ 用例覆盖全部 MCP 工具**：导入（`create_error_items`）、PDF 出处（`upload_source_page`）、检索（`search_error_items`/`search_tags`）、查重（`find_duplicates`）、修改（`update_error_item`）。点击整行即复制，`{notebook}` 用当前错题本名替换。
- **高级折叠区**：原客户端下拉 + 配置片段、Skill 版本/下载/更新命令、Key 列表（撤销）全部收进这里。设置页 `#agent-settings` 显示同一组件，高级区默认展开，避免维护两套。

### 2.3 Key 交给 AI 的方式（已确认：直接粘贴到对话）

用户确认（2026-11-11）：允许把 Key 直接粘贴给 AI，不设有效期。

- 提示词第 3 步改为：“我会把以 wnb_ 开头的 Key 发给你。请把它写进你的 MCP 配置（Codex、Claude Code、Cursor 可写入配置文件或环境变量；WorkBuddy 等替换配置里的占位符），不要写进 Git 仓库、日志或公开文件。”
- 生成 Key 时不设到期时间；高级区的到期时间输入一并去掉，已有带到期时间的 Key 照常显示和失效。
- 页面在 Key 下方提示：“Key 会留在 AI 助手的对话记录里。不用了或怀疑泄露时，到‘高级 → 管理 Key’撤销。”
- 撤销仍是唯一的失效手段，保留在高级区。

### 2.4 实现要点

- `agent-guide.tsx` 拆为 `agent/setup-prompt-card.tsx`、`agent/key-card.tsx`、`agent/examples.tsx`、`agent/advanced.tsx`；`AgentIntegrationSettings` 改为渲染同一 `AgentGuide`（`advancedOpen`）。
- `useAgentTokens.create()` 支持默认名称，不再传到期时间。
- `agentSetupPrompt()` 第 3 步按 2.3 的结论改写；中英文同步。
- 示例文案放 `t.agentGuide.examples*`，中英文 key 一致。
- 文档：README、`doc/wiki/` 中 AI Agent 接入页按新流程更新截图与步骤。
