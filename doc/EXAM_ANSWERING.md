# 试卷作答：在线做卷与拍照交卷

状态：已实现（待真机验收，2026-11-11）。主力设备为 iPad 横屏 + Apple Pencil，同时兼容手机。作答组件依赖 `doc/ANSWER_INPUT.md`，用词与风格遵循 `doc/STUDENT_UI.md`。

## 1. 问题

试卷生成后只有两个操作：

- **打印 / 导出**：打印出来在纸上做。
- **录入结果**：回到试卷页，手动给每道题选对、错或没做，选一个考试日期保存。

因此：

| # | 现状 | 后果 |
| --- | --- | --- |
| 1 | 不能在 iPad 上直接做卷 | 没有打印机就用不了试卷 |
| 2 | 纸上做完后不能拍照 | 要有人拿着答案逐题核对，再逐题点一遍 |
| 3 | 只保存对错，不保存答案 | 事后看不到当时怎么写的、错在哪 |
| 4 | 没有 AI 判题 | 复习里已有的判题能力在试卷里用不上 |

## 2. 设计原则

1. **像考试一样做**：整张卷子做完再对答案，中途不揭晓对错。逐题马上对答案是复习的做法，两者要有区别。
2. **两条路，一个结果页**：在线做和纸上做拍照，交卷后进入同一个“批改结果”页，后面的确认、订正完全一样。现有的手动录入也并进来，成为第三条路。
3. **AI 先判，人来定**：AI 的判断只是预填。只有点了“确认并保存”，结果才写入作答记录、影响掌握程度。
4. **随时能停**：答案自动保存在服务器。关掉页面、换一台设备，回来接着做。
5. **不催不比**：计时可以隐藏，不做倒计时，不显示排名和“用时超过多少人”。

## 3. 试卷页入口

试卷已生成后，标题下方的操作区改为：

| 按钮 | 说明 |
| --- | --- |
| **开始作答**（主按钮） | 进入在线做卷。有未交的卷子时显示“继续作答（已答 6/10）” |
| 打印 | 现有打印预览 |
| 拍照交卷 | 纸上做完后用 |
| 更多 → 自己录入对错 | 现有手动录入，改为进入批改结果页，所有题初始为“还没判” |

下方“作答记录”列出每一次：日期、方式（在线 / 拍照 / 手动）、对几题、状态（没交 / 批改中 / 待确认 / 已保存），点开进入对应页面。旧的手动录入结果按日期合并显示在同一列表里。

## 4. 在线做卷

### 4.1 画面（iPad 横屏，专注模式，无全局导航）

```
┌──────────────────────────────────────────────────────────────────┐
│ ✕ 保存并退出   周末小测   ⏱ 12:40   已答 6/10            [ 交卷 ]   │
│ ① ② ③ ④ ⑤ ⑥ ⑦ ⑧ ⑨ ⑩      ●已答  ○没答  ⚑等会再看                 │
├───────────────────────────────┬──────────────────────────────────┤
│ 第 7 题（10 分）                  │ [键盘] [手写] [拍照]        ⤢ 展开   │
│                               │ ┌──────────────────────────────┐ │
│ 题干、配图（可放大）              │ │                              │ │
│                               │ │  横线纸，可续纸                  │ │
│                               │ │                              │ │
│                               │ └──────────────────────────────┘ │
│ ⚑ 等会再看                      │                                  │
├───────────────────────────────┴──────────────────────────────────┤
│ ‹ 上一题                                                 下一题 ›  │
└──────────────────────────────────────────────────────────────────┘
```

- **左题右答**：与复习作答同一套分栏。右侧直接复用作答组件（键盘、手写、拍照、续纸、专心写），行为与 `ANSWER_INPUT.md` 一致。
- **题号条**：始终可见，点题号直接跳题。三种状态靠形状区分，不只靠颜色：实心是已答，空心是没答，带小旗是“等会再看”。题多于 15 道时横向滚动，当前题自动居中。
- **等会再看**：给拿不准的题插个旗，交卷前会提醒。
- **计时**：正计时，只统计页面在前台的时间。点一下计时器可以隐藏，隐藏后仍在记。
- **不显示答案和对错**：作答期间没有“答案”按钮，也不调用 AI。
- **手机与 iPad 竖屏**：单栏，题目在上、作答在下；题号条收成“7/10 ▾”，点开是题号面板；上一题、下一题固定在底部。

### 4.2 自动保存

- 每题的答案在停笔或停止输入 2 秒后、以及切题时保存到服务器。顶部用小字显示“已保存”，保存失败时显示“没保存上，正在重试”，不弹窗打断。
- 断网时继续作答，答案先留在本机，恢复后自动补传；交卷时如果还有没传上的，按钮显示“等待保存…”，不允许带着丢失的答案交卷。
- 服务器保存的是手写导出的图片。同一台设备上回来可以继续逐笔修改；换设备时，之前的笔迹显示为图片，只能整题清空重写。

### 4.3 交卷

- “交卷”放在右上角，离书写区最远；沿用 `ANSWER_INPUT.md` 第 2 节的规则，书写中和抬笔后 800ms 内不响应手掌触碰。
- 点了以后先出确认面板，不直接交：

  ```
  要交卷了吗？
  已答 8 题 · 没答 2 题（第 4、9 题）· 等会再看 1 题（第 6 题）
  [再检查一下]            [交卷]
  ```

  题号可点，点了直接回到那道题。全部答完且没有小旗时，面板只有一句“10 题都答完了”和两个按钮。
- 交卷后答案锁定，进入批改。交卷不能撤回；想重做可以再做一次，记为新的一次作答。

### 4.4 批改

- 纯文字答案与参考答案本地比对一致的，直接判对，不调用 AI（复用 `src/lib/answer-match.ts`）。
- 其余的由服务器后台逐题判题，同时进行 3 道。页面显示“正在批改 4/10”，每题判完就亮一个；学生可以离开，今天页的状态卡会出现“《周末小测》批改好了”。
- 判题任务接入后台任务防重复机制，target 为 `exam-attempt:<id>:grade`。单题失败不影响其他题，失败的题标为“还没判”，由人来选。

## 5. 拍照交卷

### 5.1 打印页的配合改动

- 卷号由试卷 ID 稳定派生为四字符，不保证全局唯一，不作为访问凭据。支持页边距盒的浏览器每页页眉印“卷号 K7Q2 · 第 1/3 页”，页脚印一行小字“做完后打开这份试卷，点‘拍照交卷’”。
- 题号改为加框的粗体数字，贴左边距，方便 AI 定位每道题的起止。
- 不印二维码：学生从试卷页进入拍照，系统已经知道是哪份试卷；卷号只用于核对拍的是不是这一份。

### 5.2 流程

```
拍照 → 检查照片 → 交卷 → 识别与批改（后台）→ 批改结果页
```

1. **拍照**：提示“一页拍一张，四个角都拍进去，光线亮一点”。可以连续拍，也可以从相册多选。每拍一张，底部多一个缩略图，显示“第 1 页”“第 2 页”。
2. **检查照片**：缩略图可以拖动排序、旋转、重拍、删除。最多 8 张。照片在本机修正方向、缩到最长边 2000px、压到 1.5MB 以内再上传（与 `ANSWER_INPUT.md` 5.2 相同）。写在另外的答题纸上也可以，照常拍。
3. **交卷**：按钮文字为“交卷，开始批改”。上传完成后学生可以离开。
4. **识别与批改**（后台，两步）：
   - **定位与转写**：每页调用一次 AI，输入这页照片和试卷的题目清单（题号、题干开头、题型），返回这页上每道题的作答区域（位置框）、作答内容的转写、纸上是否有红笔的勾或叉、是否看得清。
   - **判题**：每道题用转写内容和裁出的作答区域图，对照参考答案判对错，与在线做卷用同一个判题方法。
5. 整页模糊、反光或拍的不是这份试卷时，不进入判题，返回拍照界面并在顶部提示“第 2 页看不清，重拍这一页”，只重拍那一页即可。卷号同长度时容错 1 个字符。问题页可点“就用这几张，继续批改”，复用定位与整卷额度；看不清的页按没找到作答处理，卷号不符的页继续使用定位结果。定位失败提示“批改没能开始，再试一次”，可“重新交卷”或“自己录入对错”；后者逐题保留“还没判”，整页照片仍可翻看。

### 5.3 纸上已经批改过

如果定位步骤在至少一半有原题的题目旁看到红笔勾叉，结果页顶部显示“看到纸上已经批改过了，已按红笔结果填好”。此时：

- 预填结果以红笔为准。
- AI 判断与红笔不一致的题，归入“要看一眼”，卡片上同时显示两个结论，由人来定。

### 5.4 没找到的题

某题在所有照片里都没有找到作答，卡片显示“没找到这题的作答”，给三个选择：没做、补拍这一题（打开拍照组件，只拍这一题）、自己选对错。

## 6. 批改结果页（三条路共用）

```
┌──────────────────────────────────────────────────────────────┐
│ ‹ 周末小测 · 第 2 次 · 11月10日 · 用时 32 分钟                       │
│                                                              │
│   对 7 题 / 共 10 题        得分 74 / 100（设了分值才显示）          │
│                                                              │
│ ▍要看一眼（2）                                                  │
│ ┌──────────────────────────────────────────────────────────┐ │
│ │ 第 6 题  (还没判)   AI 说：字迹看不清第二步                      │ │
│ │ 我写的：[作答图片，点开放大；拍照的可查看整页并高亮位置]             │ │
│ │ 参考答案 ▸                              [ 对 ] [ 差一点 ] [没做] │ │
│ └──────────────────────────────────────────────────────────┘ │
│ ▍差一点（2）  ……                                               │
│ ▍做对的（6）  ▸ 默认折叠                                         │
│                                                              │
│                                   [ 确认并保存 ]（还有 2 题没判）   │
└──────────────────────────────────────────────────────────────┘
```

- **顺序**：先是“要看一眼”（AI 没法确定、与红笔不一致、没找到作答），再是“差一点”，最后是“做对的”（折叠）。需要人处理的永远在最上面。
- **每张卡片**：题号、结果章、我写的（图片或文字，AI 转写可展开）、参考答案与解析（折叠）、判题依据、三个结果按钮。AI 判错但学生认为对的，直接点“对”，等同于复习里的“我觉得我是对的”；改过的卡片标注“已改”。
- **确认并保存**：固定在底部。还有“还没判”的题时不可用，并显示剩余数量。保存后：
  - 每题写入一条作答记录（来源为试卷），带作答图片、AI 转写、判题依据和用时，时间为交卷时间。
  - 重新评估相关原题的掌握程度，并同步复习安排（与现在手动录入的行为一致）。
  - 页面变为只读，顶部出现“搞定”章；“差一点”的题各有一个“去订正”按钮，打开原题详情。
- 保存后发现判错了：页面右上“改结果”，改完再保存一次，旧记录被替换，不产生重复记录。
- 试卷作答不计入复习连续天数（现有口径：只算复习），在 `doc/PRACTICE_HISTORY.md` 的做题记录里显示为一行，可展开。

## 7. 数据与接口

### 7.1 数据模型（需要迁移，备份格式 17 → 18）

| 模型 | 字段 |
| --- | --- |
| `ExamAttempt`（新增） | id、userId、paperId、kind（online / photo / manual）、status（answering / grading / reviewing / done）、startedAt、submittedAt、confirmedAt、durationSec、pageImages（JSON：各页照片的存储键）、pageIssues（问题页）、pageLocations（定位缓存）、gradingUsageId（整卷额度记录） |
| `ExamAttemptAnswer`（新增） | id、attemptId、examQuestionId、answerText、answerImageUrl、gradingImages、gradingRetries、flagged、pageIndex 与 region（拍照定位）、recognizedAnswer、handMark、aiResult、aiReason、finalResult |
| `PracticeRecord` | 新增可空列 `examAttemptId`，把一次作答的各题记录关联起来 |

- 迁移只新增表和列，旧程序兼容；旧的手动录入记录没有 `examAttemptId`，按时间分组显示。
- 每份试卷同一时间只允许一个未交的作答。删除试卷时作答一并删除，已保存的作答记录保留（与现在一致）。
- 导出、导入、`src/lib/backup/format.ts`、`data-backup.test.ts` 同步；旧版备份没有这两张表，导入时跳过。
- `src/lib/image-maintenance.ts` 要认识新表引用的图片，避免当成孤立文件清理。
- 作答区域裁剪在服务器用现有的 jpeg-js / pngjs 完成，不引入原生依赖。

### 7.2 接口

| 接口 | 用途 |
| --- | --- |
| `POST /api/exams/:id/attempts` | 新建作答；已有未交的则返回它 |
| `GET /api/exams/:id/attempts/:aid` | 读取作答、各题答案与批改进度 |
| `PUT .../answers/:questionId` | 在线做卷自动保存（文字、图片、小旗） |
| `POST .../pages`、`DELETE .../pages/:index` | 拍照交卷上传、删除某页；追加携带 `expected` 照片快照，删除可携带 `reference` 防止重复删除后一页 |
| `PUT .../pages` | 按 `expected` 快照整体替换顺序与内容，仅接受本次作答已有引用或新照片 data URL |
| `GET .../pages/:index/image` | 鉴权读取整页照片 |
| `POST .../answers/:questionId/regrade` | 单题重判；拍照作答可附 `photos`（1–3 张）补拍，共用最多两次重判限制 |
| `POST .../submit` | 交卷，启动后台批改；可选 `force: true` 仅对有问题页的拍照作答生效 |
| `POST .../manual` | 定位失败后转入手动待确认，保留拍照来源与整页照片 |
| `PATCH .../answers/:questionId` | 结果页改某题的结果 |
| `POST .../confirm` | 确认并保存，写入作答记录 |
| `DELETE .../attempts/:aid` | 放弃一次没保存的作答 |

### 7.3 AI

- 新增业务方法“试卷页面定位与转写”，实现在 `BaseAIProvider`，提示词放 `prompts/`，解析放 `response-parser.ts`；多图沿用 `ANSWER_INPUT.md` 的 `images` 传输。
- 判题从 `/api/practice/grade` 中抽出共用函数，参考答案取自试卷题目（新题模式下不是原题的答案）。
- 输出上限经 `withModelOutputLimit`，不写死。

### 7.4 隐私

试卷照片会上传并保存在服务器（用于回看和裁剪作答区域），并发送给所配置的 AI 提供商。这一点与单题拍照作答“原图不保存”不同，`doc/PRIVACY.md` 与 `PRIVACY.en.md` 需要单独写明。

## 9. 风险

- **定位出错**：题目跨页、答案写到别的题旁边、字迹潦草时，AI 可能把答案配错题。应对是结果页每题都显示裁出的作答图，配错了一眼能看出来，并可查看整页。
- **批改等待**：10 道手写题大约需要 30–60 秒。应对是后台进行、可离开、完成后在今天页提示。
- **AI 用量**：一次拍照交卷约等于“页数 + 题数”次调用，比单题判题多。计费口径见下面第 3 条。

## 10. 已确认

1. 在线做卷采用“整卷交完再看对错”，不逐题揭晓。
2. 计时显示正计时、可隐藏，不做倒计时。
3. 一次交卷的 AI 批改按 1 次计入每日 AI 次数，token 按实际计入月用量。
4. 纸上已有红笔批改时，以红笔为准，AI 不一致的题提示人工确认。
5. 新题模式下做错的新题不自动收进错题本，只记在原题的作答记录里。
6. 试卷照片保存在服务器供回看。

## 11. E5 实现细节与待验收

- `pageIssues` 保存问题页数组，`pageLocations` 按图片引用缓存定位结果，重排复用缓存，重拍只定位变化页。两字段并入未合并主线的作答迁移与备份 v18，旧备份缺省为空。确认后清空定位缓存。
- 题目区域外扩 3% 后复用服务端来源页裁剪工具。跨页作答最多保留四张判题图，展示图使用首张，全部图片送判。超过四个区域保守标记看不清，交由人工确认。整页照片保留供回看，确认后临时判题图回收。
- 定位与判题共用整卷额度、后台任务及模型输出上限。MiniMax Code OAuth 适配器仅补充向基类业务方法的委托。
- iPad Safari、Apple Pencil、横竖屏与手机真机走查，以及真实手写试卷的定位和判题准确率验收待完成。
